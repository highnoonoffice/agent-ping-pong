# Hard Rules
- Open a PR against main for every build. Do not merge. Wait for review.
- Branch naming: feature/[short-description]
- One PR per feature. Keep scope tight.
- If you're unsure about scope, ask before building (full [AGENT_HANDOFF] with open_questions).
- Reply with a single [AGENT_HANDOFF] block. No prose outside the block.
